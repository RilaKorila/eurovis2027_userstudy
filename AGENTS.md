# Local secrets

Treat `.streamlit/secrets.toml` as a private runtime file. Do not open, read, search, copy, attach, or disclose it, including through shell commands, scripts, or browser and file tools. Exclude it from recursive searches and archives. Use the documented setting names and synthetic test credentials for development. If the active environment does not enforce the repository's deny rules, follow this instruction anyway. Run production credential checks through the app from the user's own terminal.
